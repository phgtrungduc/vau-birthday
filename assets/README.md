# Assets

Đặt các file sau vào thư mục này:

| File | Mô tả |
|------|--------|
| `background.jpg` | Ảnh nền full màn hình (khuyến nghị ≥ 1920×1080) |
| `music.mp3` | Nhạc nền (bật/tắt bằng nút góc trên phải) |

Nếu chưa có `background.jpg`, trang vẫn chạy với nền gradient dự phòng.
Nếu chưa có `music.mp3`, nút nhạc sẽ không phát được âm thanh cho đến khi bạn thêm file.
